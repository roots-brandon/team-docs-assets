# roots-cards

The team's chat card kit, one script per skill (`pm.js` for roots-pm, `care.js` for roots-customer-care-reply). Built from `kits/roots-cards/` and each skill's `cards/` folder in the roots-team repo; never edited here by hand.

Styling, layout and the code that writes each card's answer only: no customer or team data lives here. A skill's `assets/stub.html` pins the commit it was built with, so keep old commits; pin a commit, never `@main`.

pm-cards/ is the earlier roots-pm-only kit; roots-pm 1.5.4 and older still load it.
